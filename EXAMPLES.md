## Usage Patterns

### Pattern 1: Quick Generation

**Input**:
```
Create a 5-slide pitch about AI automation
```

**Output**: Basic slide deck with title, problem, solution, benefits, CTA

### Pattern 2: Content Conversion

**Input**:
```
Convert this blog post into slides:
[paste 2000-word blog post]
```

**Output**: 8-10 slides extracting key points, adding structure

### Pattern 3: Detailed Specification

**Input**:
```
Generate slides with:
- Topic: Product roadmap
- Theme: Minimal Corporate
- Slides: Title, Q1 goals, Q2 goals, Q3 goals, Q4 goals, Resources needed, Timeline, CTA
- Include timeline visualization
```

**Output**: Exactly specified slide deck with custom layouts

### Pattern 4: LinkedIn to Slides

**Input**:
```
Turn this LinkedIn post into a slide deck:

"5 lessons from scaling to $10M ARR:
1. Focus on one customer segment
2. Build for retention, not acquisition
3. Hire slowly, fire quickly
4. Automate everything
5. Listen to customers obsessively"
```

**Output**:
- Slide 1: Title - "5 Lessons from Scaling to $10M ARR"
- Slide 2-6: One lesson per slide with expansion
- Slide 7: Summary and CTA

## Customization Examples

### Adding Custom Animations

```html
<style>
@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-20px); }
}

.bounce-in {
  animation: bounce 0.6s ease;
}
</style>
```

### Custom Slide Layout

```html
<div class="slide slide-custom">
  <div class="slide-content">
    <div style="display: grid; grid-template-columns: 2fr 1fr; gap: 40px;">
      <div>
        <h2>Main Content</h2>
        <p>Details here</p>
      </div>
      <div>
        <img src="image.jpg" alt="Visual">
      </div>
    </div>
  </div>
</div>
```

### Adding Charts

```html
<div class="chart-container">
  <svg viewBox="0 0 400 200">
    <rect x="50" y="50" width="40" height="100" fill="var(--primary)"/>
    <rect x="120" y="30" width="40" height="120" fill="var(--secondary)"/>
    <rect x="190" y="70" width="40" height="80" fill="var(--accent)"/>
  </svg>
</div>
```

## Best Practices from Examples

### Content Structure
- Start with a strong hook
- One idea per slide
- Use visual hierarchy
- End with clear CTA

### Visual Design
- Consistent spacing
- Limited color palette
- High contrast text
- Generous white space

### Storytelling
- Problem → Solution → Proof → Action
- Use data to support claims
- Include social proof (quotes, logos)
- Create emotional connection

### Technical Quality
- Test on multiple devices
- Ensure fast loading
- Validate accessibility
- Check print layout

## Testing Checklist

Before finalizing any slide deck:

- [ ] Content is clear and concise
- [ ] Visual hierarchy is obvious
- [ ] All text is readable
- [ ] Colors have sufficient contrast
- [ ] Animations are smooth
- [ ] Navigation works on all devices
- [ ] Speaker notes are complete
- [ ] File size is optimized
- [ ] Tested in multiple browsers
- [ ] Accessible to screen readers
- [ ] Print layout is acceptable
- [ ] No spelling or grammar errors
