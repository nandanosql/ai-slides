# AI Slides - Quick Reference

One-page guide to generating amazing presentations.

## 🚀 Quick Start

```
Generate a 5-slide pitch deck about [topic] with [theme] theme
```

## 🎨 Themes

| Theme | Best For | Style |
|-------|----------|-------|
| `minimal-corporate` | Business, corporate | Clean, professional |
| `apple-keynote` | Product launches | Bold, minimal |
| `dark-futuristic` | Tech talks | Dark, neon accents |
| `ai-startup` | Investor pitches | Gradient, modern |
| `data-storytelling` | Analytics, reports | Chart-focused |

## 📊 Slide Types

- **Title** - Hero text with subtitle
- **Content** - Bullets and text
- **Quote** - Large quote with attribution
- **Stats** - Animated number dashboard
- **Timeline** - Milestones with dates
- **Comparison** - Before/After, A vs B
- **Chart** - Bar, pie, line graphs
- **CTA** - Call-to-action with button
- **Divider** - Section separator

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `→` or `Space` | Next slide |
| `←` | Previous slide |
| `Home` | First slide |
| `End` | Last slide |
| `F` | Fullscreen |
| `S` | Speaker notes |
| `T` | Change theme |
| `ESC` | Exit fullscreen |

## 📱 Mobile

- **Swipe left** - Next slide
- **Swipe right** - Previous slide
- **Tap controls** - Access features

## 🎯 Best Practices

### Content
- ✅ One idea per slide
- ✅ 3-5 bullets max
- ✅ Large, readable text
- ✅ High contrast

### Design
- ✅ Consistent spacing
- ✅ Visual hierarchy
- ✅ White space
- ✅ Purposeful color

### Technical
- ✅ Test in browser
- ✅ Check mobile view
- ✅ Verify accessibility
- ✅ Keep file <150KB

## 🔧 Customization

### Change Theme
Press `T` during presentation

### Edit Content
Open HTML file in text editor

### Add Images
```html
<img src="image.jpg" alt="Description">
```

### Embed Video
```html
<video src="video.mp4" controls></video>
```

3. **PDF** - Print to PDF
4. **Images** - Screenshot slides

## 🆘 Troubleshooting

| Issue | Solution |
|-------|----------|
| Slides don't load | Enable JavaScript |
| Animations choppy | Close other tabs |
| Theme not changing | Press `T` key |
| Mobile gestures fail | Swipe on slide area |

## ✨ Pro Tips

1. **Start simple** - Generate basic deck first, then refine
2. **Use themes** - Choose theme that matches audience
3. **Test early** - Open in browser to verify
4. **Add notes** - Include speaker notes for context
5. **Keep focused** - One message per slide
6. **Use visuals** - Stats, charts, quotes break up text
7. **Practice** - Run through before presenting
8. **Have backup** - Export to PDF just in case
