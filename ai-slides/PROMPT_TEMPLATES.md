# Prompt Templates

AI prompt patterns and templates for intelligent slide generation, content optimization, and story structuring.

---

## Core Prompt Patterns

### 1. Content Analysis & Optimization

**Pattern**: Analyze input content and optimize for slide presentation

```
Analyze this content and optimize it for a slide presentation:

[USER CONTENT]

Tasks:
1. Identify key messages and main points
2. Rewrite for clarity and impact
3. Create strong hooks for each section
4. Suggest visual elements (icons, charts, images)
5. Structure into logical slide flow
6. Ensure each slide has one clear message

Output format:
- Slide 1: [Title] - [Key message] - [Visual suggestion]
- Slide 2: [Title] - [Key message] - [Visual suggestion]
...
```

### 2. Story Flow Structuring

**Pattern**: Create narrative arc for presentation

```
Structure this content into a compelling story:

[USER CONTENT]

Apply this narrative framework:
1. Hook: Grab attention (problem/question)
2. Context: Set the stage (background)
3. Conflict: Present the challenge
4. Solution: Introduce your approach
5. Evidence: Show proof/data
6. Impact: Demonstrate results
7. Call-to-Action: Next steps

For each section, provide:
- Slide title
- Key message (1 sentence)
- Supporting points (3-5 bullets)
- Visual recommendation
```

### 3. Content Summarization

**Pattern**: Condense long content into slide bullets

```
Summarize this content into slide-ready bullets:

[USER CONTENT]

Requirements:
- Maximum 5 bullets per slide
- Each bullet: 6-10 words
- Use active voice
- Start with action verbs
- Remove filler words
- Maintain key insights
- Ensure parallel structure
```

### 4. Visual Suggestion Engine

**Pattern**: Recommend visuals for content

```
Suggest visual elements for these slides:

[SLIDE CONTENT]

For each slide, recommend:
1. Icon/emoji (if applicable)
2. Chart type (bar, pie, line, timeline)
3. Image style (photo, illustration, diagram)
4. Color emphasis (highlight key words)
5. Layout type (single column, two column, grid)

Consider:
- Content type (data, concept, story)
- Audience level (technical, general)
- Presentation context (pitch, report, keynote)
```

## Conversion Templates

### LinkedIn Post → Slides

```
Convert this LinkedIn post into a slide deck:

[LINKEDIN POST]

Structure:
1. Title slide: Main hook from post
2. Problem slide: Challenge mentioned
3. Solution slides: Key points (1 per slide)
4. Proof slide: Stats/results if mentioned
5. CTA slide: Call-to-action

Optimization:
- Expand abbreviated points

- Create visual hierarchy
- Suggest relevant charts/icons
```

### Blog Post → Presentation

```
Transform this blog post into a presentation:

[BLOG POST]

Process:
1. Extract main thesis → Title slide
2. Identify 3-5 key sections → Content slides
3. Pull out quotes → Quote slides
4. Extract data/stats → Stats slides
5. Summarize conclusion → CTA slide

Guidelines:
- One idea per slide
- Simplify complex paragraphs
- Highlight key phrases
- Add section dividers
- Create visual breaks
```

```
Create a presentation from these meeting notes:
```

## Slide Type Templates

### Title Slide

```
Create a compelling title slide:

Topic: [TOPIC]
Audience: [AUDIENCE]
Context: [CONTEXT]

Generate:
- Main title: Bold, clear, memorable (3-7 words)
- Subtitle: Context or value prop (8-12 words)
- Optional: Date, presenter, company
- Visual: Suggest background style or accent

Tone: [Professional/Bold/Friendly/Technical]
```

### Problem Slide

```
Frame the problem compellingly:

Problem: [PROBLEM DESCRIPTION]

Create:
- Title: "The Challenge" or specific problem statement
- Hook: Why this matters (1 sentence)
- Impact: Who is affected (2-3 bullets)
- Urgency: Why now (1 sentence)
- Visual: Icon or simple illustration

Make it relatable and urgent.
```

### Solution Slide

```
Present the solution clearly:

Solution: [SOLUTION DESCRIPTION]

Structure:
- Title: Clear solution statement
- How it works: 3-4 key features
- Benefits: What users gain
- Differentiator: Why it's better
- Visual: Diagram or process flow

Focus on value, not features.
```

### Stats/Data Slide

```
Visualize data effectively:

Data: [DATA POINTS]

Create:
- Title: Key insight from data
- Primary metric: Largest, most important
- Supporting metrics: 2-4 additional stats
- Context: Comparison or benchmark
- Chart type: [Bar/Pie/Line/Number]

Make numbers tell a story.
```

### Quote Slide

```
Design an impactful quote slide:

Quote: [QUOTE TEXT]
Author: [AUTHOR]

Format:
- Large, centered quote text
- Attribution below
- Optional: Author photo or company logo
- Minimal design, maximum impact

Use for testimonials, expert opinions, or key insights.
```

### Timeline Slide

```
Create a timeline visualization:

Events: [LIST OF EVENTS WITH DATES]

Structure:
- Title: "Our Journey" or "Roadmap"
- Timeline: Horizontal or vertical
- Milestones: Key events with dates
- Highlights: Major achievements
- Future: What's next

Visual: Connected dots or line with markers.
```

### Comparison Slide

```
Show before/after or A vs B:

Comparison: [WHAT'S BEING COMPARED]

Layout:
- Title: "Before vs After" or "Option A vs B"
- Two columns: Side-by-side
- Key differences: 3-5 points each
- Visual distinction: Color or icons
- Conclusion: Which is better and why

Make differences clear and obvious.
```

### CTA Slide

```
Create a strong call-to-action:

Goal: [WHAT YOU WANT AUDIENCE TO DO]

Elements:
- Title: Clear action statement
- Primary CTA: Main action (button style)
- Secondary info: Contact, link, QR code
- Urgency: Why act now
- Visual: Minimal, focus on CTA

Make the next step obvious and easy.
```

## Content Optimization Rules

### Clarity Enhancement

```
Original: [ORIGINAL TEXT]

Optimize for:
1. Simplicity: Remove jargon
2. Brevity: Cut unnecessary words
3. Impact: Use power words
4. Clarity: One idea per sentence
5. Action: Start with verbs

Output: Optimized version
```

### Hook Creation

```
Topic: [TOPIC]

Create 3 hook options:
1. Question hook: Provocative question
2. Stat hook: Surprising statistic
3. Story hook: Brief anecdote

Each hook should:
- Grab attention immediately
- Relate to audience pain point
- Lead naturally into content
- Be under 15 words
```

### Bullet Point Optimization

```
Original bullets:
[LIST OF BULLETS]

Optimize:
- Parallel structure: Same grammatical form
- Action verbs: Start with strong verbs
- Consistent length: Similar word count
- Logical order: Most to least important
- Remove redundancy: No repeated ideas

Output: Optimized bullets
```

## AI Decision Trees

### Theme Selection Logic

```
Input: [PRESENTATION CONTEXT]

Decision tree:
1. Is it a business/corporate presentation?
   → Yes: Minimal Corporate
   → No: Continue

2. Is it a product launch or design showcase?
   → Yes: Apple Keynote
   → No: Continue

3. Is it tech/developer/AI focused?
   → Yes: Dark Futuristic
   → No: Continue

4. Is it a startup pitch or investor deck?
   → Yes: AI Startup Pitch
   → No: Continue

5. Is it data-heavy or analytics focused?
   → Yes: Data Storytelling
   → Default: Minimal Corporate
```

### Slide Type Selection

```
Content: [SLIDE CONTENT]

Determine slide type:
1. Contains quote or testimonial?
   → Quote slide

2. Contains 3+ data points or metrics?
   → Stats dashboard

3. Contains dates or sequential events?
   → Timeline slide

4. Comparing two things?
   → Comparison slide

5. Asking audience to do something?
   → CTA slide

6. Introducing new section?
   → Section divider

7. Default: Content slide with bullets
```

### Chart Type Selection

```
Data: [DATA DESCRIPTION]

Choose chart type:
1. Showing parts of a whole?
   → Pie chart

2. Comparing categories?
   → Bar chart

3. Showing trend over time?
   → Line chart

4. Showing process or sequence?
   → Timeline or flow diagram

5. Showing relationship between variables?
   → Scatter plot

6. Single important number?
   → Large animated counter
```

## Quality Assurance Prompts

### Slide Review Checklist

```
Review these slides for quality:

[SLIDE CONTENT]

Check:
1. ✓ One clear message per slide
2. ✓ Consistent visual hierarchy
3. ✓ No more than 5 bullets per slide
4. ✓ Readable font sizes
5. ✓ Proper contrast
6. ✓ Logical flow between slides
7. ✓ Strong opening and closing
8. ✓ Visual variety (not all text)
9. ✓ Consistent tone
10. ✓ Clear call-to-action

Flag any issues and suggest improvements.
```

### Accessibility Check

```
Ensure slides are accessible:

[SLIDE CONTENT]

Verify:
1. Text contrast ratio ≥ 4.5:1
2. Font size ≥ 16px for body text
3. Alt text for images
4. Color not sole indicator
5. Keyboard navigable
6. Screen reader friendly
7. Clear focus indicators

Report any accessibility issues.
```

## Advanced Patterns

```
Adapt this presentation for different audiences:

Create versions for:
1. Executive audience: High-level, business impact
2. Technical audience: Details, implementation
3. General audience: Simple, relatable

- Adjust language complexity

- Modify visuals

```

### Presentation Length Optimization

```
Adjust presentation length:

Original: [SLIDE COUNT] slides
Target: [TARGET COUNT] slides

If reducing:
- Combine related slides
- Remove supporting details
- Focus on key messages
- Merge similar points

If expanding:
- Break complex slides
- Add examples
- Include more data
- Add transition slides
```

```
Adapt presentation for [TARGET CULTURE]:

Original: [CONTENT]

Consider:
- Color meanings
- Symbol interpretations
- Communication style (direct/indirect)
- Humor appropriateness
- Example relevance
- Visual preferences

Suggest modifications for cultural fit.
```

## Usage Guidelines

### When to Use Each Pattern

- **Content Analysis**: Starting from scratch with raw content
- **Story Flow**: Need narrative structure
- **Summarization**: Long content to condense
- **Visual Suggestion**: Need design guidance
- **Conversion Templates**: Transforming existing content
- **Slide Type Templates**: Creating specific slide types
- **Optimization Rules**: Improving existing slides
- **Decision Trees**: Automated theme/type selection
- **Quality Assurance**: Final review before delivery

### Combining Patterns

Patterns can be chained for comprehensive slide generation:

1. Content Analysis → Extract key points
2. Story Flow → Structure narrative
3. Slide Type Selection → Choose layouts
4. Visual Suggestion → Add design elements
5. Optimization → Polish content
6. Quality Assurance → Final review

### Customization

All patterns can be customized by:
- Adjusting tone (formal/casual)
- Changing emphasis (data/story)
- Modifying structure (linear/modular)
- Adapting length (brief/detailed)
